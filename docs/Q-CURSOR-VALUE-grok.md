## 1. Does Pro+ enlarge the included Cursor Models pool, or only Other Models ($20 → $70)?

**Short answer:** it is **not** “same Grok/Composer tank + more third-party credits + Grok Bot.” Staff say the first-party pool **does** grow with the plan. Cursor **will not publish the size or the multiplier**. The only *numeric* upgrade they print is Other Models **$20 → $70**, plus **Grok Bot**.

### What the official pages actually print

Two pools. Only one of them has numbers.

| Plan | Price | Other Models (third-party API) | Cursor Models (Composer 2.5, Cursor Grok 4.5 / 4.6) |
|---|---|---|---|
| Pro | $20/mo | **$20** | “Generous included usage” |
| Pro+ | $60/mo | **$70** | “Generous included usage” |
| Ultra | $200/mo | **$400** | “Generous included usage” |

Sources (all **OFFICIAL**):

- [cursor.com/docs/models-and-pricing](https://cursor.com/docs/models-and-pricing) — table above, identical Cursor Models cell on every paid tier, including India Start.
- [cursor.com/help/account-and-billing/pricing](https://cursor.com/help/account-and-billing/pricing) — plan table is *only* “Included Other Models usage”: $20 / $70 / $400. No Cursor Models column at all.

**OFFICIAL:** the published dollar ladder is Other Models only. **$20 → $70 is 3.5×, not 3×.** The pricing page’s “3x” is attached to **Agent**, and historically to “OpenAI, Claude, Gemini,” not to Composer/Grok.

**OFFICIAL:** Pro+ also adds **Grok Bot**. Pro does not. Ultra and Teams do. SuperGrok $30 does not. SuperGrok Plus ($100) and Heavy do. Sources: [cursor.com/help/grok-bot/plans](https://cursor.com/help/grok-bot/plans), [x.ai/news/grok-bot-more-plans](https://x.ai/news/grok-bot-more-plans) (21 Aug 2026).

### How a user knows they hit it

Yes, there **is** a meter. It is a **percentage bar**, not a grok.com-style “X% of weekly pool with product breakdown” — but it is a real remaining-allowance surface.

**OFFICIAL:** Spending tab shows real-time usage for **both** pools, remaining allowance, on-demand charges. Editor notifies on limit. ([usage-limits](https://cursor.com/help/models-and-usage/usage-limits))

**REPORTED:** users post screenshots of “Cursor Models” hitting **100%**. Heavy Grok 4.6 use is a documented way to empty it. ([forum.cursor.com/t/169032](https://forum.cursor.com/t/possible-bug-in-cursor-token-statistics-other-models-disabled-after-grok-quota-exhausted/169032); [t/164062](https://forum.cursor.com/t/hit-a-monthly-limit-on-auto-model-pro-plan/164062) Auto on Pro hitting a hard monthly stop.)

There is **no** public equivalent of grok.com’s Settings → Usage product breakdown (Chat / Imagine / Voice / Build). Cursor’s meter is two bars: Cursor Models and Other Models.

### What happens at the limit — not a throttle, a stop, then a spill

This is the piece the docs bury and staff finally said in August 2026.

**STAFF (deanrie, 23 Aug 2026)** — [forum.cursor.com/t/169032](https://forum.cursor.com/t/possible-bug-in-cursor-token-statistics-other-models-disabled-after-grok-quota-exhausted/169032):

1. Named third-party models (GPT, Claude, Gemini, DeepSeek, …) draw **only** from Other Models.
2. Cursor models (Auto, Composer, Cursor Grok) draw from **Cursor Models first**.
3. When that pool is empty they **automatically continue from remaining Other Models**.
4. When both are empty: **hard stop**, unless on-demand is enabled. Then pay-as-you-go at the same API rates. Quality/speed are **not** degraded. ([models-and-pricing](https://cursor.com/docs/models-and-pricing), [overages](https://cursor.com/help/account-and-billing/overages))

**OFFICIAL:** on-demand is **off by default**. Without it, “those models will just pause until the monthly reset, they won’t start charging you.” (deanrie, [t/167296](https://forum.cursor.com/t/what-does-this-really-mean/167296); [overages](https://cursor.com/help/account-and-billing/overages))

**OFFICIAL:** there is no slow/throttled remainder on current usage-based plans. Unlimited Auto was killed; staff said so when a Pro user hit a hard Auto stop. ([t/164062](https://forum.cursor.com/t/hit-a-monthly-limit-on-auto-model-pro-plan/164062))

So: **percentage meter → 100% → spill into leftover Other Models credits → hard stop, or on-demand if you turned it on.** Not a secret throttle. Not grok.com Extra Credits unless you enable Cursor on-demand.

**UNKNOWN:** any internal fair-use ceiling above the percentage bar. Not published.

**Not documented as the same deployment.** Closest honest statement:

| | grok.com / xAI API `grok-4.6` | Cursor “Cursor Grok 4.6” |

Cursor Pro **does** give CLI access to **Cursor’s** Grok 4.6 via Cursor CLI. It does **not** give the Grok Build binary, Grok Build’s weekly SuperGrok pool, or grok.com chat.

---

If you only care about coding, here is the honest trade: **do not cancel SuperGrok to “get Grok in Cursor.”** Cursor Pro already includes Cursor Grok 4.6 and Composer on a monthly included pool; SuperGrok is what you lose Imagine, Voice, Expert, grok.com chat, the weekly usage dashboard, and Grok Build for. If the $30 is mostly paying for those consumer features, Cursor Pro $20 does not replace them. If the $30 is mostly paying for a coding agent, Cursor Pro is the actual coding product — Tab, repo context, Composer, Claude/GPT when you need them, Cloud Agents — and its Grok is a Cursor-hosted 256k coding variant, not grok.com. **Pro+ is the wrong lever unless you are burning the $20 Other Models pool, hitting the unpublished Cursor Models bar, or you specifically want Grok Bot.** The $40 delta is not a bigger published Grok tank; staff say the tank does grow, Cursor will not say by how much, and the only number on the receipt is $70 of third-party credits plus Bot. Stay on Pro, watch [cursor.com/dashboard/usage](https://cursor.com/dashboard/usage) for a month, and only climb if that percentage bar, not the marketing page, says you have a problem.

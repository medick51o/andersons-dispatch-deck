## 2. Suggest vs. summon

Spend is irreversible. A standing permit is a **PLAN-CARD field the boss writes**. The orchestrator may not grant itself one.

| Act | Allowed |
|---|---|
| **Silent summon** (announce the wrap, do not wait) | Only with a standing permit: `composer-2.5` (**not** `-fast`), purpose named in the permit, daily cap not hit, Cursor Models pool, fresh call, files in the repo before the call ends |
| **Suggest** (one line, wait) | Default. Any Other Models family. First use of a family. T4 not met. the operator’s “long Kimi review.” Any `-fast`. Effort `max`/`xhigh`. T5. |
| **Explicit ruling** | On-demand. Any `claude-*` / `gpt-*` / `gemini-*` through Cursor. Bench as sole builder of a write-set. Bench in a council. Cursor Grok while house Grok is up. Changing the wrapper default. |
| **Hard refuse — do not even offer** | On-demand as a continuation path. W1–W11. `auto` as a reviewer. Reply-chain dressed as a review. “House was slow so I used Fast.” |

**Suggest line:** *“Bench T1: Moonshot eyes on this Claude-built review. Cheap door: `composer-2.5` on Cursor Models. Expensive door: `kimi-k3-high` on Other Models (API $3/$15 — Sonnet rates). House alternative: Codex. Permit: none. Spin which, or neither?”*

Silent summon still narrates. Hide the spend and it is theft: `♾️ composer-2.5 reviewing parser ♾️` or `💸 kimi-k3-high 💸`. Cursor Models = ♾️ wrap. Other Models = 💸 wrap. On-demand (forbidden) would be 🚨💳.

```
cursor_bench:                    # PLAN-CARD, boss-owned
  status: RESERVE                # not a house seat
  on_demand: FORBIDDEN
  other_models: included-only    # $20 then STOP
  expected_other_models_spend: $0
  standing_permit: []            # boss fills; empty = suggest-only
  daily_other_models_cap: 0      # auto-summon of Other Models = none
  daily_cursor_models_cap: 3     # even the "included" pool is capped
  default_slug: composer-2.5     # NOT composer-2.5-fast
```

Spend ledger (jsonl, one row per call): `date · slug · pool · trigger · purpose · session_id · tokens`. Read it before every summon. The wrapper already prints tokens in the footer — log them.

**Pool empty or plan lapses:** bench = `DEAD`. LIMP HOME on house seats. Do not retry. Do not promise “finish on Cursor tomorrow.” Do not enable on-demand. Cursor’s own docs offer on-demand or an upgrade at the cap — this shop picks **neither** at dispatch time. Upgrade is a boss ruling outside the run.

**What actually breaks on lapse (the failure mode):** reply-chains die; `sessionId` goes invalid; an in-flight review vanishes; the orchestrator “helpfully” retries on-demand. The bench must never be the sole builder of a write-set — a house seat must be able to finish the lane. If the bench dies mid-review, that review is incomplete; fall back to a house reviewer. Do not pause the mission for a metered seat.

**The included-pool launder:** “Cursor Grok / Composer is on Cursor Models, so summon freely” is how a $20 shop burns the generous tank, then treats empty as permission to open Other Models, then treats empty Other Models as permission to go on-demand. Each step sounds cheap. Cap both pools. Expected monthly Other Models spend ≈ $0. If the weekly lineage review shows Other Models spend without a T1/T3/T5 row, that is abuse, flagged to the boss.

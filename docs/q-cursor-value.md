# RESEARCH: what does Cursor Pro+ ($60) actually add over Pro ($20)?

Two people need this answered with evidence, not marketing copy. Cite URLs. Label every claim
OFFICIAL / REPORTED / UNKNOWN. Do not fill a gap with a guess.

## Question 1 — the one that matters most

**Does Cursor Pro+ increase the INCLUDED "Cursor Models" pool (Composer, Cursor Grok) compared to
Pro, or does it only increase the "Other Models" third-party credit allowance from $20 to $70?**

Cursor's own pricing page uses the identical phrase — "generous included usage" — for Pro, Pro+ and
Ultra, and their marketing "3x limits" appears to refer to the Agent / Other Models ladder. If that
is right, then a user paying $40 more per month gets **the same free Grok/Composer tank** plus more
credits, and nothing else except Grok Bot. Verify or refute that, hard. Look at:
- the pricing page, the docs pricing page, usage-limits help pages
- release notes or changelogs that changed plan limits
- Cursor forum posts from STAFF (not users) about Cursor Models limits per tier
- anything that states an actual number, rate, or ratio for the included pool at any tier

If Cursor genuinely does not differentiate the included pool by tier, say so plainly. If they do,
quote the number.

## Question 2 — what is the included pool's actual size?

Anything real: a token cap, a request cap, a rate limit, a "you have used X%" surface, a fair-use
threshold, staff statements, or credible user reports of hitting it. How would a user even KNOW they
had hit it? Is there a usage meter for Cursor Models the way grok.com has one? What happens at the
limit — hard stop, throttle, or spill into paid credits?

## Question 3 — what does someone LOSE trading SuperGrok $30 for Cursor Pro $20?

A specific person is considering exactly this trade. Enumerate honestly what SuperGrok $30 provides
that Cursor Pro $20 does not, including but not limited to:
- grok.com chat itself, and its usage
- Grok Imagine (image/video generation)
- Grok Voice
- Expert mode / any reasoning modes
- the Grok Build CLI (does Cursor Pro provide any equivalent CLI access to Grok?)
- model versions: is Cursor's `cursor-grok-4.6` the same model as grok.com's Grok 4.6, or a
  Cursor-hosted variant with different behaviour, context window, or tool access?
- anything else material

And the reverse: what does Cursor Pro $20 give that SuperGrok $30 does not?

## Deliverable
Three sections answering the three questions. Tables where useful. End with a plain paragraph:
"if you only care about coding, here is the honest trade" — written for someone deciding this week.
